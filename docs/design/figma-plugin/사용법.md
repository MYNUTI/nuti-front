# 피그마 프로토타입 자동 배선 — 사용법

40개 화면의 클릭 연결 **97개를 자동으로** 만들어주는 전용 플러그인입니다. 수작업으로 선을 긋지 않아도 됩니다.

## 준비

시안 40화면이 피그마에 임포트되어 있어야 합니다 (`00 전체 40화면 (격자 배치).html`, 뷰포트 2262).

## 설치 (한 번만)

1. 피그마 데스크톱 앱 실행 — **웹 브라우저 버전에서는 안 됩니다** (로컬 플러그인은 데스크톱 전용)
2. 상단 메뉴 **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 **`manifest.json`** 선택

## 실행

1. 시안 40화면이 있는 **페이지를 연 상태**에서
2. **Plugins → Development → 마이뉴티 프로토타입 배선**
3. 창이 뜨면 **[배선 실행]** 클릭 (10~30초)

옵션 2개는 켜둔 채로 두시면 됩니다:
- **프레임 이름 정리** — 프레임 이름을 `01 스플래시`, `02 처리방침 동의` … 로 바꿔줍니다
- **시작 화면 지정** — 프로토타입 재생 시 01 스플래시부터 시작

## 확인

피그마 우상단 **▶ 재생 버튼** → 실제로 눌러보며 이동을 확인할 수 있습니다. 공유도 여기서 됩니다.

## 결과 창 읽는 법

```
화면 인식: 40 / 40
프레임 이름 정리 완료
연결 생성: 97개
```

- **인식 수가 40 미만이면**: 못 찾은 화면 이름이 표시됩니다. 그 화면이 임포트 안 됐거나 텍스트가 바뀐 경우입니다
- **건너뜀이 있으면**: 해당 버튼 텍스트를 피그마에서 수정하셨을 가능성이 큽니다 (플러그인은 버튼 문구로 위치를 찾습니다)
- 여러 번 실행해도 안전합니다 (기존 연결을 덮어씀)

## 작동 원리

화면을 **크기(390×844)와 고유 문구**로 식별하고, 버튼 문구를 찾아 그 버튼 상자에 `클릭 → 해당 화면으로 이동` 반응을 넣습니다. 배선 내용은 `화면 플로우·인터랙션 명세` 문서와 동일합니다.

## 문제가 생기면

- **"화면 프레임을 찾지 못했습니다"** → 시안이 있는 페이지가 열려 있는지 확인
- **플러그인이 목록에 안 보임** → 데스크톱 앱인지 확인, manifest.json을 다시 임포트
- 배선을 되돌리려면: 피그마에서 `Ctrl+Z` (실행 직후) 또는 프레임 선택 후 Prototype 탭에서 연결 삭제
