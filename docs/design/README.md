## 핵심 컴포넌트 — 마커형 등급 히어로

`07 첫 결과.png` / `12 결과 펼침.png` 참조. 5칸 램프(A~E) 위에 현재 등급 배지가 **자기 칸 바로 위**에 노치로 앉는 구조입니다. A면 왼쪽 끝, E면 오른쪽 끝으로 배지가 이동합니다 — 이 이동이 "5단계 중 내 위치"를 형태로 보여주는 장치라 반드시 구현해야 합니다. 스플래시 로고·PWA 아이콘도 같은 램프 모티프입니다.

## 구현 시 주의

- 상태바·키보드 영역은 그리지 않았습니다 (실기기가 렌더)
- 등급은 **색 단독 금지** — 색 + 문자(A~E) + 램프 위치
- 카드는 그림자 없이 헤어라인 보더(`--hairline`)
- 자세한 규칙은 저장소 루트 `DESIGN.md`

## 클릭 프로토타입 · 화면 플로우

- **클릭 프로토타입**: `prototype/index.html` — 브라우저로 열면 40화면을 실제로 눌러 이동할 수 있습니다. 「클릭 지점 표시」 버튼을 켜면 눌 수 있는 요소가 점선으로 보입니다. (온라인 링크는 팀 채널 공유본 참조)
- **화면 플로우·인터랙션 명세**: `FLOW.md` — 플로우 다이어그램 + 화면별 [누르는 것 → 이동] 97건 + 역방향 진입 경로. **구현 시 이 문서가 화면 전이의 단일 원본입니다.**
- **피그마 자동 배선 플러그인**: `figma-plugin/` — 피그마에 임포트한 시안을 **최상위로 승격 + 사용자 여정 순서로 재배치**하고 프로토타입 연결 97개를 자동 생성합니다 (수작업 배선 불필요). 사용법은 그 폴더의 `사용법.md`.
  - 배치: 온보딩 한 줄 → 핵심 루프(+비교·대안 분기) → 탐색 → 데이터 기여 → 재방문 → 설정, 밴드마다 섹션 제목
